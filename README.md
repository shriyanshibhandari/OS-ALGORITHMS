## Operating System Synchronization
This repository contains some Java programs that I have implemented as part of my Operating System coursework. 
These programs help in understanding how different processes or threads work together and share resources safely.

## Programs Included
### Dining Philosophers
This program demonstrates the Dining Philosophers problem and shows how semaphores can be used to manage shared resources and avoid conflicts between philosophers.

### Producer Consumer
This program demonstrates how producers and consumers work with a shared buffer. Semaphores are used to make sure that the processes access the buffer properly.

### Reader Writer
This program demonstrates the Reader-Writer problem, where multiple readers can access shared data while writers need controlled access.

## Concepts Used
- Process Synchronization
- Semaphores
- Mutual Exclusion
- Critical Section
- Shared Resources
- Concurrency
