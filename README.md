# Operating System Algorithms

This repository contains programs implemented as part of my Operating System coursework. These programs demonstrate important OS concepts, including process synchronization, resource management, and deadlock avoidance.

## Programs Included

### 1. Dining Philosophers Problem (Java)
Demonstrates the Dining Philosophers problem and the use of semaphores to manage shared resources, ensure mutual exclusion, and avoid conflicts between philosophers.

### 2. Producer-Consumer Problem (Java)
Demonstrates communication between producers and consumers using a shared buffer. Semaphores are used to synchronize access and ensure proper buffer management.

### 3. Reader-Writer Problem (Java)
Demonstrates the Reader-Writer problem, allowing multiple readers to access shared data simultaneously while ensuring controlled access for writers.

### 4. Banker’s Algorithm (C)
Implements the Banker’s Algorithm to check whether a system is in a safe state. It uses the allocation, maximum requirement, need, and available resource information to determine a safe sequence of processes and help avoid deadlocks.
